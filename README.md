# デッキラボ

紙のデュエマのデッキ作成、AI対戦、対戦結果の分析を行う、スマホを優先したWebアプリです。

## 起動・検証

Node.js 22以上で、外部npm依存のインストールなしに起動できます。

```sh
npm run dev
# http://127.0.0.1:4173/
npm test
npm run check
```

`dist/`を静的サイトとして配信できます。対戦の計算はWeb Worker、OCRは端末内のTesseract.jsで処理します。写真・デッキ情報を外部APIへ送る処理はありません。

## 実装済み

- 公式カード名の全件取得、同名再録の集約、カード名検索、デッキ編集と端末内保存
- 全登録名での初手5枚・シールド5枚・ドロー練習、配り直し
- 初手と追加ドローで各カード1枚以上、または指定した最大5種類がすべてそろう確率（厳密値と最大10,000回の試行）
- 全登録カードの名前・文明・コスト・種類・能力文を公式ページから取得して保存、能力文を含む検索と絞り込み
- ツインパクト・裏面などを面ごとに表示し、文明・コスト・種類の組み合わせは同じ面で照合
- コスト0・∞・公式欄の空欄を区別し、コストバランスは面1の数値コストを集計
- 写真撮影・画像選択、日本語OCR、読み取り候補と枚数の確認・修正
- テキスト・JSONによるデッキ入力、JSON出力、構成を埋め込んだ共有リンク、友達のデッキ登録
- 相手デッキの「作る」「選ぶ」「環境デッキを選ぶ」。自分用と同じカード一覧・写真・リストの作成画面を使い、登録済みの相手やマイデッキからも選択できます。初期の相手デッキはありません。
- 相手用のデッキは自分用とは別に端末内保存。マイデッキから選ぶ場合は独立したコピーを作り、相手を編集しても元のマイデッキは変わりません。
- 個別または登録した相手すべてとの自動対戦。「アカウントから選ぶ」は今後対応予定の案内で、アカウント検索・公開デッキの取得・端末間同期は未実装です。
- 「新しいデッキを作る」から開いた作成画面の「環境デッキを選ぶ」ボタンから公式DMGP2026-1st Day2入賞リスト3件を選択し、40枚をそのまま自動作成・端末保存。出典・使用者・成績・確認日を表示し、同じ40枚の既存デッキは重複追加しない
- 手動対戦、効果の対象選択、ブロック・S・トリガーの選択、練習モードのヒント・待った
- 実対戦から算出する勝率、先後別勝率、95% Wilson信頼区間、序盤のカード使用状況
- 履歴、対戦ログの再生、結果の書き出し
- 改良前後で相手・乱数・回数・先後を合わせた比較

## 対応範囲

**カード名の登録と、カード効果を処理できる範囲を区別します。** 公式検索の同名集約リストを全ページ取得し、名称を掲載しているカードをデッキ登録・初手確認に利用します。検索件数、名称取得件数、名称未掲載項目、同名集約後の件数は `dist/catalogue.json` に記録しています。NFKC、空白の連続、引用符の字体差を同名判定で整えます。カードの別名・能力面の異なるツインパクトを省略して結合することはありません。

各登録名について、公式の代表ページから名前・文明・コスト・種類・能力文を取得し、`dist/details.json` に保存します。能力の段落とS・トリガー等の記号を保持します。複数面では、それぞれの情報を独立して表示・検索します。情報が不足する場合は同名の再録ページも確認し、名前・面構成を照合して、情報が多く元の項目が欠けないページを採用します。採用した出典は `detailSource` に記録します。それでも公式欄が空欄の場合は推測で補わず「未掲載」と表示します。能力文を取得したことによって、対戦用の効果処理が実装された扱いにはしません。

対戦対応は277種類です。第2段階で、W・Tブレイカーと既存キーワードの組み合わせを持つ通常単色クリーチャー173種類を追加しました。従来のDM-01の44種類に、第1段階として効果付き9種類と能力なしの通常単色クリーチャー51種類を追加しました。各カードに公式情報へのリンクを記録しています。公式総合ゲームルールVer.1.53（2026-10-15）と2026-10-20確認の殿堂レギュレーションを基準に、対応カードで発生する処理を実装しています。公式・公認アプリではなく、全裁定の再現を保証しません。

第1段階で追加した効果付きカードは、フェアリー・ライフ、エナジー・ライト、デーモン・ハンド、ナチュラル・トラップ、ホーリー・スパーク、アクア・サーファー、スパイラル・スライダー、ロスト・ソウル、解体屋ピーカプです。任意の効果を見送る選択、コスト条件付きの対象、除去先、S・トリガーによる無料使用、召喚酔いを受けない攻撃を処理します。未実装の効果識別子は読み込み時に拒否します。

全11,833種類の効果自動処理は開発途中です。能力文を一般的なAIに読ませて効果を推測したり、未対応カードを能力なしとして対戦させたりはしません。第1段階の追加対象は `tools/expand-support.mjs` の明示的なリストに限り、能力なしカードは一面・通常クリーチャー・単色・数値コストとパワー・空である能力文を再照合します。同名判定が未整備の別表記カードは追加対象から外しています。「対応範囲とルール」から対応数と今回追加した効果を確認できます。

効果未対応カードは使用制限が未確認のため、保存用として同名1〜40枚を受け付けます。これは大会での使用可否や合法な構築の判定ではありません。初手確認は40枚のメインデッキ専用で、別ゾーンを混ぜずに使います。効果によるドローやサーチ、マリガンは行いません。先攻・後攻のドロー枚数は自分で指定します。

マナ支払いは必要な文明を含む組み合わせを自動選択します。対戦AIは固定のルールに基づく判断で、非公開の相手手札、両者のシールド、山札の順番を判断材料にしません。自動対戦の勝率は、このAI・対応カード・相手構成の条件下の結果です。カード使用と勝率の相関を因果効果として表示しません。

### 未対応

- 対戦対応リスト以外の効果、多色・進化・革命チェンジ等、アドバンスと外部ゾーン
- 効果未対応カードの使用制限・特殊構築条件の判定
- 環境ランキングの自動更新、任意のカードから大会デッキを生成する機能
- アカウント、端末間同期、オンライン対人戦、公開デッキ投稿と公開範囲設定
- 別の行動を選んだ分岐を再実行する分析

相手の基本デッキ3つは一覧から外しています。登録した相手から選ぶほか、マイデッキからのコピーやカードからの新規作成、環境デッキの選択に対応します。未登録時は対戦開始を無効にして選択方法を表示します。マイデッキと過去の対戦履歴は保持し、履歴からの比較・リプレイは当時の相手構成を使用します。画像認識はカード名のOCRで、イラストからの物体識別ではありません。未知カードを既知カードとして自動確定せず、候補確認を必須にしています。解像度や角度により読み取れない画像はリスト入力で補います。

マイデッキ画面上部の「環境」「デッキを作成」ボタンは外し、デッキ一覧内の「新しいデッキを作る」から作成画面を開きます。環境デッキの閲覧中にカード一覧へ戻っても編集中の内容は保持し、内容がある場合の大会リスト作成には確認を表示します。

「環境デッキを選ぶ」から作成するデッキは、公式に掲載された大会当時の固定リストです。最新環境の順位や現在の大会での使用可否を保証しません。2026-10-20に公式リストを確認し、バイケン（Grimoire・優勝）、ドギラゴン王道（ピンキ→・準優勝）、光水闇邪眼帝（サラー・TOP8）を収録しています。自分用にも相手用にも選択して保存できますが、すべて効果未対応カードを含むため、手動・自動対戦は既存の検証で拒否します。自分用では保存・編集・初手・ドローの確認に利用できます。基本デッキ3つの一括追加機能はありません。

## 保存・共有

デッキ・最新16件の自動対戦結果はブラウザのlocalStorageに保存します。履歴の各相手について最大8戦の勝敗サンプルと再現用乱数を保持します。ページを閉じると進行中の手動対戦は失われます。写真は保存しません。端末やブラウザを変えてもデータは自動同期されません。

共有リンクにはデッキ名と構成が含まれます。パスワードや友達限定のアクセス制御はありません。Site本体が非公開の場合、リンク先を開くにはSiteへのアクセス権も必要です。デッキの持ち運びにはJSON出力も利用できます。

- `tools/fetch-cards.mjs`、`tools/prepare-data.mjs`：公式情報の取得とOCR配布物の準備

## カード名の更新

```sh
npm run sync:catalogue
npm run sync:details
npm run check
```

公式検索の同名集約結果をすべて読み、8接続以内・リトライと待機を含めて名前を取り込みます。取得済み情報はGit対象外の`tools/research/catalogue/`に保存し、中断から再開できます。検索件数が変わった場合はキャッシュを別の場所へ退避して再実行します。全件を照合できるまで配布用JSONを置き換えません。名前のない公式項目はIDと出典を記録し、存在しない名前を補いません。チェックは取り込み途中のプレビューを拒否します。新しいカード効果は自動実装しません。

カード詳細も8接続以内で取得し、公式ページのHTMLを圧縮したキャッシュと解析済みデータをGit対象外の `tools/research/details/` に保存します。途中で中断しても取得済みページから再開できます。全登録名を照合できるまで配布用JSONを更新しません。公式欄に空欄のある項目は `missingFields` と `partialCount` で分かるようにし、空欄の能力文と未掲載の能力文欄も区別します。数値以外のコストを0に変換しません。

公式の更新情報を取り直す場合は `npm run sync:details -- --refresh` を実行します。通常の再実行では取得済みデータを再利用し、確認日は元の取得日を維持します。

## v0.8 対戦カードの第2段階

- 対応104種類から277種類へ。追加173種類は `tools/support-phase-2.json` にカードID・出典・照合用の能力文全文・処理する特性を固定しています。内訳は複数ブレイカー56種類（W 46 / T 10）、ブロッカー87、スピードアタッカー17、スレイヤー20、ブロックされない7です。複数の能力を持つカードは重複します。
- `node tools/expand-keyword-support.mjs` で再構築。通常の単色クリーチャー、完全な公式情報、数値のコスト・パワー、確認時の能力文全文と特性の一致を必須とします。能力文から任意のカードを自動的に対戦対応へ昇格させません。固定リスト以外・未知の文章・未対応のブレイカーを拒否します。
- ブレイカーで指定された数（シールドが少なければその数）を重複なく選び、同時にブレイク。最後のシールドを破っても、その攻撃をダイレクトアタックにはしません。ブロックされた場合はブレイクしません。
- 複数のS・トリガーは全カードの使用宣言を終えてから、守る側が使用順を選択。S・トリガーのクリーチャーの「出た時」は全トリガーの使用が終わるまで待機し、その後で解決順を選べます。途中で山札切れの敗北が確定すれば残りの処理を止めます。
- [公式総合ルール1.53](https://dm.takaratomy.co.jp/img/dm_rule_20261015.pdf) 112.3a / 509.2–509.6 と [公式Q&A](https://dm.takaratomy.co.jp/rule/qa/38750/) を参照。2026-10-20の殿堂レギュレーションのカード名と今回の追加リストに一致なし。
- `tests/keyword-expansion.test.mjs` で全173種類の特性、同時ブレイク、複数トリガー、出た時の待機、山札切れ、AIの非公開情報、混成デッキでの80枚の保存と乱数再現性を検証します。
- 多色・進化・シールド焼却などは未対応。収録環境デッキ3件も効果の対応待ちです。過去の対戦結果には旧エンジンのバージョンを保持します。旧エンジンの結果の勝率は保存したまま表示し、異なるエンジンでのリプレイ再現や同一条件の比較は制限します。
